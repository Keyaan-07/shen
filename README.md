# SHEN
Shen is a low-cost pico-sized RP2350A development board along with the raspberry pi RM2, in a small 21mmx51mm form factor, with USB-C support. It is a 4 layer stackup with 1.0mm thickness.  

Check out the PCB online on [KiCanvas](https://kicanvas.org/?repo=https%3A%2F%2Fgithub.com%2FKeyaan-07%2Fshen%2Ftree%2Fmain%2Fhardware)

## Features
- WiFi and Bluetooth support
- dual-core
- 4MiB Flash storage(expandable upto 16MiB)
- User-LED
- High efficiency sychronous buck converter
- USB Boot
